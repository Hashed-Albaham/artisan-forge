# Security Policy

## Supported Versions

We actively provide security patches, vulnerability remediation, and static analysis updates for the following releases:

| Version | Supported          |
| ------- | ------------------ |
| 2.5.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

The Production Code Artisan project takes software security and injection protection with the utmost seriousness.

If you discover a security flaw, bypass in anti-slop rules, or potential vulnerability in this repository or any of its skills:

1. **Do NOT open a public GitHub issue.**
2. Email your vulnerability report to: `security@artisan-ai.dev` (or open a Private Vulnerability Advisory on GitHub).
3. Include detailed reproduction steps, example payloads, and impact assessment.
4. Our security team will acknowledge your report within 24 hours and provide regular progress updates until a patch is released.
