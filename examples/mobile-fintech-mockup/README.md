# Example: iOS Mobile Fintech Mockup Specification

This example showcases how `muapi-ui-design` coordinates Atomic Design components into a production layout for iOS (393×852, 9:16 aspect ratio, safe-area padded).

Run the generation command:
```bash
./skills/muapi-ui-design/generate-mockup.sh \
  --prompt "Decentralized crypto staking wallet with live APY telemetry and one-tap deposit" \
  --platform ios \
  --theme dark \
  --output ios_staking_wallet.png
```
