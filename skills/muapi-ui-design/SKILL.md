# 🎨 UI/UX Design Mockup Skill (muapi-ui-design)

**A specialized skill for AI Agents to architect high-fidelity digital interfaces.**
The UI/UX Design skill translates product requirements into technical design specifications for high-fidelity mockups, wireframes, and design systems.

---

## 🌟 Core Competencies

1. **Atomic Design Orchestration**: Structuring interfaces from Atoms (buttons, inputs) to Molecules (search bars, stat widgets), Organisms (navbars, card grids), and Templates/Pages.
2. **Platform-Specific Layouts**: Designing for responsive breakpoints across Mobile (iOS Human Interface Guidelines, Android Material Design 3) and Web (Enterprise SaaS, E-Commerce, Dashboards).
3. **Design System Integration**: Specifying typography scales (Major Third, Perfect Fourth), spacing tokens (4px/8px grid), and accessible color palettes (WCAG AAA/AA compliance).
4. **Heuristic Awareness**: Ensuring designs follow established usability principles (Nielsen's 10 Heuristics: visibility of system status, match between system and real world, error prevention).

---

## 💻 CLI Usage via generate-mockup.sh

```bash
# Generate Web SaaS Dashboard Mockup
./generate-mockup.sh --platform web --theme dark --prompt "Real-time Kubernetes monitoring cluster overview"

# Generate iOS Mobile App Screen
./generate-mockup.sh --platform ios --theme light --prompt "Fintech crypto savings wallet with transaction feed"
```
